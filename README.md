# Оборона дирижабля · Zeppelin Defense

Браузерная 3D-игра на **three.js** с настоящей **Voronoi-фрактурой** обломков
(`three-pinata`) и **физикой твёрдых тел** (`Rapier`/`@dimforge/rapier3d-compat`).
Сбитые самолёты и дирижабль реально разлетаются на куски, которые падают с
гравитацией, кувыркаются, горят и тянут за собой дымные шлейфы.

## Миссия
Удержать дирижабль **2 минуты**. Истребители заходят волнами, бьют тем точнее,
чем ближе подлетают, проскакивают мимо, делают петлю и идут на второй круг.
Часть из них отделяется и охотится за тобой. У дирижабля, у тебя и у врагов —
свой запас прочности.

## Управление
- **TAB** — переключение режимов.
- **Пулемёт** (стоишь на месте): мышь — наводка в конусе **±45°**, **ЛКМ** — огонь,
  **R** или кнопка на HUD — перезарядка (+30 патронов). Двигаться нельзя.
- **Полёт** (свободно летаешь, стрелять нельзя): **W/S** тангаж, **A/D** крен,
  **Q/E** рыскание, **Shift/Ctrl** газ. В полёте пулемёт скрыт; за пулемётом
  немного видно твой борт.

Синий самолёт — твой (с крутящимся пропеллером на реалистичной скорости).
Красные бипланы — враги (модель WW1). Серый — дирижабль.

## Бэкенд / защита от «скачивания через F12»
Игра отдаётся Express-сервером. Полностью спрятать клиентский WebGL нельзя, но:
- логика идёт только минифицированным бандлом (`/bundle.js`, без source-map);
- тяжёлые модели и HDR-небо лежат за `/asset/:name` и требуют одноразовый
  серверный токен (выдаётся на загрузке страницы, живёт 5 минут) + совпадение
  Origin/Referer. Прямой запрос `.glb` из новой вкладки или curl → `403`;
- результат раунда валидируется на сервере (`/api/score`).

## Локальный запуск
```bash
npm install      # ставит зависимости и собирает бандл (postinstall → build)
npm start        # http://localhost:3000
```
Пересборка клиента после правок `src/main.js`: `npm run build` (или `npm run watch`).

## Деплой на Render
Репозиторий содержит `render.yaml` (Blueprint). На render.com:
**New → Blueprint → выбрать этот репозиторий**. Render выполнит
`npm install && npm run build` и поднимет `npm start` (порт берётся из `$PORT`).

## Ассеты (в `assets/`, отдаются только через токен)
| файл | роль |
|------|------|
| `player_plane.glb` | твой борт (перекрашен в синий, узел `пропеллер` крутится) |
| `enemy_ww1.glb`    | вражеский истребитель WW1 (красный) |
| `airship.glb`      | дирижабль |
| `machine_gun.glb`  | пулемёт (ствол + турель-«кабина») |
| `sky.hdr`          | HDR-небо (окружение + фон + отражения) |

## Где что в коде (`src/main.js`)
- `fractureMesh()` / `proxyFragments()` — Voronoi-разбиение меша на обломки и
  превращение их в Rapier-тела.
- `updateDebris()` — шаг физики, синхронизация мешей, тление и дымный шлейф.
- `updateEnemies()` / `enemyFire()` — ИИ заходов, петля, преследование, стрельба.
- `updateGunCamera()` / `updateFlight()` — две камеры и два режима.
- Тюнинг (размеры/повороты моделей, скорость пропеллера, время раунда, HP,
  конус наводки) — в объекте `CFG` сверху файла.
